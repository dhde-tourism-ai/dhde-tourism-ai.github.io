# dhde.me

Organization site for dhde.me. For now `index.html` only redirects to the map at `/dhde-app/`.

- Change where dhde.me goes: edit the two `/dhde-app/` paths in `index.html` (and the link) and push to `main`.
- Other repos in this organization with GitHub Pages are served under the same domain, e.g. `dhde.me/dhde-app/` and `dhde.me/dhde-madinah/`.
- DNS (Namecheap): four A records for `@` to 185.199.108.153, .109, .110 and .111, and `www` as a CNAME to `dhde-tourism-ai.github.io`. Content changes never need DNS changes.
